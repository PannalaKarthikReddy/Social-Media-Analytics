# Social Media Analytics — Project Insights

## 1. Executive Summary

This project analyzes social media performance across platforms, campaigns, content types, time slots, and time periods.

The analysis focuses on identifying patterns in reach, engagement, and engagement rate to understand which combinations of platform, content, campaign, and posting time are associated with stronger performance.

---

## 11. Key Analytical Takeaways

### 1. Engagement rate varies across platforms

The platform comparison shows measurable differences in average engagement rate across Facebook, Instagram, LinkedIn, and YouTube.

### 2. High-performing posts form a distinct segment

Using an engagement-rate threshold of 12.02%, 500 posts were identified as high-performing.

### 3. Reels appear frequently among high-performing content

Reels represent a substantial portion of high-performing content across Facebook, Instagram, LinkedIn, and YouTube.

### 4. Campaign performance differs by content format

The campaign analysis demonstrates that the same campaign can contain multiple content formats with different engagement and reach characteristics.

### 5. Posting time can be analyzed alongside platform

The platform × time-slot analysis provides a more detailed view than analyzing posting time independently.

## 12. Business Questions Answered

This project addresses questions such as:

4. Which posting time slots perform differently across platforms?
5. How does social media performance change over time?
6. What characteristics are common among high-performing posts?
7. How does performance differ between 2025 and 2026?
