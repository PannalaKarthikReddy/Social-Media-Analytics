# Dataset

This folder contains the datasets used for the Social Media Analytics project.

## Files

- `raw_social_media_data.csv` — Original/raw social media dataset.
- `social_media_data.csv` — Dataset used for the analysis workflow.
- `social_media_data_cleaned.csv` — Cleaned dataset prepared for analysis and visualization.

### Data Workflow

Raw Data → Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights
